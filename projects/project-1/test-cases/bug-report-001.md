# Баг-репорт #1: Товар не добавляется в корзину

## Основная информация
- **Серьезность:** Критическая
- **Приоритет:** Высокий 
- **Браузер:** Microsoft Edge 142.0.3595.80
- **ОС:** Windows 11
- **Дата обнаружения:** 19.11.2024

## Описание
После успешного добавления товара в корзину товар отсутствует при переходе в корзину.

## Шаги воспроизведения
1. Перейти в категорию Laptops
2. Выбрать товар
3. Нажать "Add to cart"
4. Перейти в корзину

## Результаты
- **Ожидаемый:** Товар в корзине
- **Фактический:** Корзина пуста
