# Тест-кейс: Добавление товара в корзину

## Проверка функции добавления товара из категории "Laptops" в корзину
### Приоритет: Высокий
### Предусловие: Пользователь находится на главной странице https://demoblaze.com/index.html

| № | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | В разделе "Categories" нажать на категорию "Laptops" | Отображается список ноутбуков |
| 2 | Нажать на название первого товара в списке | Открывается страница с описанием товара |
| 3 | На странице товара нажать кнопку "Add to cart" | Появляется всплывающее сообщение "Product added" |
| 4 | В верхнем меню нажать "Cart" | Происходит переход в корзину |
| 5 | Проверить наличие добавленного товара в корзине | В корзине отображается товар, который был добавлен |
| 6 | Проверить корректность отображения данных товара | Название, цена и изображение товара соответствуют странице товара |
