# Чек-лист: Тестирование корзины товаров

## Основные проверки
- [ ] Кликабельность кнопок интерфейса
- [ ] Отклик при нажатии на кнопку "Добавить в корзину"
- [ ] Всплывающее уведомление об успешном добавлении
- [ ] Товар отображается в корзине с верным количеством

## Детальные проверки
- [ ] Название товара в корзине соответствует выбранному
- [ ] Цена товара в корзине правильная
- [ ] Количество товара = 1 (по умолчанию)
- [ ] Общая сумма рассчитывается корректно
