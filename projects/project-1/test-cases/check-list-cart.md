# Чек-лист: Тестирование корзины товаров

## Проверки
- [ ] Кликабельность кнопок интерфейса
- [ ] Отклик при нажатии на кнопку "Добавить в корзину"
- [ ] Всплывающее уведомление об успешном добавлении
- [ ] Товар отображается в корзине с верным количеством (1)
- [ ] Товар в корзине соответствует выбранному
- [ ] Цена товара правильная
