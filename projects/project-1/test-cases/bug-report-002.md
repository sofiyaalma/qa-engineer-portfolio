# Баг-репорт #002: В поле Логин можно ввести более 50 символов

## Основная информация
- **Серьезность:** Незначительная
- **Приоритет:** Низкий 
- **Браузер:** Microsoft Edge 142.0.3595.80
- **ОС:** Windows 11
- **Дата обнаружения:** 26.11.2024

## Описание
После ввода более 51 и более символов в поле Логин нет сообщения об ошибке

## Шаги воспроизведения
1. Перейти по ссылке https://codepen.io/sabundhal/pen/jOvEVwG
2. В поле логин ввести 51 цифру

## Результаты
- **Ожидаемый:** Сообщение об ошибке
- **Фактический:** Подсказки подсвечиваются зеленым, сообщения об ошибке нет
