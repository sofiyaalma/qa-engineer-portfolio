# Тест-кейс: Проверка формы регистрации

## Верстка обязательных полей ввода и их валидация
### Приоритет: Высокий
### Предусловие: Пользователь находится на странице https://codepen.io/sabundhal/pen/jOvEVwG

| № | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Перейти по ссылке, убедиться, что стенд с разработанной формой доступен и форма регистрации отображается корректно | Стенд с разработанной формой доступен, поля не плывут |
| 2 | Проверить наличие полей: Логин, Пароль, Повторение пароля | Поля присутствуют |
| 3 | Рядом с обязательными полями имеются всплывающие подсказки, которые объясняют особые условия или ограничения для вводимой информации | При наведении курсора на поле ввода появлется подсказка (кроме поля "Повторите пароль") |
| 4 | При вводе значений в поля "Пароль" и "Повторите пароль" значение маскируется | Значение приобретает вид маскирующих точек |
| 5 | Форму невозможно отправить, если не заполнено какое-либо из полей | У незаполненного поля вслывает подсказка о заполнении |
| 6 | Форму невозможно отправить, если она пуста | У поля "Логин" вслывает подсказка о заполнении |

#### Какие техники тест дизайна применялись: 
- Функциональное тестирование
- Попарное тестирование
