# Тест-кейс: Проверка формы регистрации (негативный сценарий)

## Валидация данных в полях формы регистрации
### Приоритет: Высокий
### Предусловие: Пользователь находится на странице https://codepen.io/sabundhal/pen/jOvEVwG

| № | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | В поле Логин ввести 2 цифры | Все подсказки подсвечиваются красным |
| 2 | В поле Логин ввести 2 английские буквы | Подсказка Минимум 3 символа подсвечивается красным, подсказка Должен содержать только буквы и цифры (без специальных символов) подсвечивается зеленым |
| 3 | В поле Логин ввести 51 цифр | Подсказки подсвечиваются красным |
| 4 | В поле Логин ввести 51 английскую букву | Подсказки подсвечиваются красным |
| 5 | В поле Пароль ввести Hhhhh7! | Подсказка о количестве символов подсвечивается красным |
| 6 | В поле Пароль ввести Hhhhh7!, в поле Повторите пароль ввести Hhhhhh7! | Поля Пароль и Повторите пароль подсвечиваются красным |
